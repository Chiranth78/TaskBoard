# **App Name**: TaskGrid

## Core Features:

- Grid Task View: Display tasks in a grid format, similar to Grid Diary, allowing users to visually organize and prioritize tasks.
- Task Management: Enable users to create, update, and delete tasks with detailed descriptions, due dates, and priority levels, mirroring Google Tasks functionality.
- Drag and Drop: Implement drag-and-drop functionality within the grid to allow users to easily reschedule or reprioritize tasks.
- Journal Section: Allow users to input progress made daily, weekly, monthly, and yearly. Reflect ongoing and completed tasks in the journal for respective dates. Allow addition of other content to journal entries.
- Calendar Consistency Tracker: Display a calendar indicating the user's consistency in making diary entries.

## Style Guidelines:

- Primary color: Light beige (#F5F5DC) for a soft, diary-like feel.
- Secondary color: Muted green (#A9D18E) to indicate task completion.
- Accent: Coral (#FF7F50) to highlight important deadlines or urgent tasks.
- Clean and readable sans-serif font for task descriptions.
- Simple and intuitive icons for task categories and priority levels.
- Grid-based layout with clearly defined cells for each day or task category.
- Smooth transitions when dragging and dropping tasks within the grid.
